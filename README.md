This code was generated by [Magic Patterns](https://magicpatterns.com) for this design: [Source Design](https://www.magicpatterns.com/c/btwclqzkv8bqyzd8v3elyy)

## Getting Started

1. Run `npm install`
2. Run `npm run dev` (open `http://localhost:5173/humber-river-pals/`)

## GitHub Pages

The site deploys automatically from `main` via GitHub Actions.

1. Push these changes to `main`.
2. In the repo on GitHub: **Settings → Pages → Build and deployment → Source**, choose **GitHub Actions**.
3. After the workflow finishes, the site is live at  
   **https://brandonpanday.github.io/humber-river-pals/**

Static images live in `public/` and are referenced in components via `publicAsset('filename.jpg')`.

| File | Used on |
|------|---------|
| `hrp-logo-nav.png` | Navbar, footer |
| `hrp-transparent.png` | Full-resolution logo (optional) |
| `about-organizers-1.jpg`, `about-organizers-2.jpg` | About page |
| `672992571_…_n.jpg` (and 4 similar) | Home volunteer gallery |
